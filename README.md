# CloudMusic

- pyside6使用分支，可以在pyside6 下学习使用这个软件, windows环境中执行
```
pyside6-rcc .\qml.qrc -o qml_rc.py
pyside6-rcc .\js.qrc -o js_rc.py
pyside6-rcc .\res.qrc -o res_rc.py
python main.py
```
